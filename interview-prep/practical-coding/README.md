# "Practical" Coding Practice Problems
Practice coding problems for places which do not do traditional leetcode style coding interviews. Questions are intended to have you build small systems like you would see in real life.

## How to run a solo mock with these
1. Paste only Setup + Part A into your editor, timer on, talk out loud the entire time (record yourself).
2. Reveal parts as you clear them.
3. Afterward grade: reached Part C bug-free? Tests written per part? Talked while typing?
